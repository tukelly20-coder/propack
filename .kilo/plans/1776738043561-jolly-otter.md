# Kế hoạch khắc phục lỗi - Cần thực hiện

## Vấn đề được xác định

### 1. Lỗi API nghiêm trọng: `GET /api/customers` - Status 500

**Nguyên nhân**: Schema database thiếu các cột.

- **File lỗi**: `server.py:1438-1474` - Endpoint `/api/customers`
- **Query trong endpoint**:
  ```sql
  SELECT code, name, phonetic, english_name FROM customers
  ```
- **Schema DB hiện tại** (`db_helper.py:init_db_v2()`):
  ```sql
  CREATE TABLE customers (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name VARCHAR(200) UNIQUE NOT NULL,
      contact_person VARCHAR(100),
      phone VARCHAR(50),
      email VARCHAR(100),
      address TEXT
  )
  ```
- **Các cột thiếu** so với query: `code`, `phonetic`, `english_name`

**Hậu quả**:
- SQLite throw: `no such column: code`
- API trả về status 500
- Frontend `projects.js:1248` (function `loadCustomers`) receive error
- Projects tab: không load được danh sách khách hàng

### 2. Cảnh báo accessibility (KHÔNG NGHIÊM TRỌNG)
- Input password thiếu `autocomplete` attributes trên trang Profile (section Profile)
- Đây chỉ là warning, không blocking chức năng

---

## Giải pháp đề xuất

### Thay đổi 1: Cập nhật `init_db_v2()` trong `src/db_helper.py`

**Vị trí**: function `init_db_v2()` around lines 74-84

**Thay đổi**: Sửa CREATE TABLE customers statement để bao gồm đủ 9 cột:

```python
cursor.execute('''
    CREATE TABLE IF NOT EXISTS customers (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        code VARCHAR(50),
        name VARCHAR(200) UNIQUE NOT NULL,
        phonetic VARCHAR(100),
        english_name VARCHAR(200),
        contact_person VARCHAR(100),
        phone VARCHAR(50),
        email VARCHAR(100),
        address TEXT
    )
''')
```

**Mục đích**: Đảm bảo DB mới tạo có đầy đủ columns như endpoint expects.

---

### Thay đổi 2: Thêm ALTER TABLE migration trong `migrate_to_v2()`

**Vị trí**: function `migrate_to_v2()` around lines 378-388 (ngay sau CREATE TABLE customers)

**Thay đổi**: Thêm block migration code:

```python
# Migration: Thêm các cột mới cho customers (nếu chưa có) - CHO DB CŨ
try:
    cursor.execute('ALTER TABLE customers ADD COLUMN code VARCHAR(50)')
except sqlite3.OperationalError:
    pass  # Column đã tồn tại
try:
    cursor.execute('ALTER TABLE customers ADD COLUMN phonetic VARCHAR(100)')
except sqlite3.OperationalError:
    pass  # Column đã tồn tại
try:
    cursor.execute('ALTER TABLE customers ADD COLUMN english_name VARCHAR(200)')
except sqlite3.OperationalError:
    pass  # Column đã tồn tại
```

**Mục đích**: Apply schema changes cho database đã tồn tại (không mất data).

## Rủi ro & Mitigation

| Rủi ro | Mức độ | Mitigation |
|--------|--------|------------|
| Migration ALTER TABLE fail do DB lock | Thấp | Restart server đảm bảo không có connection nào mở |
|Existing customers không có `code` value | Trung bình | Endpoint filter `WHERE code IS NOT NULL` → những customers thiếu code sẽ không hiển thị. Cần admin update sau. |
| Column order khác nhau giữa DB cũ và mới | Thấp | SQLite không quan tâm order, SELECT * hay SELECT column cụ thể đều OK |

## Tóm tắt

- **Root cause**: customers table thiếu 3 columns (`code`, `phonetic`, `english_name`)
- **Fix**: Update schema via `init_db_v2()` + `migrate_to_v2()` trong `db_helper.py`
- **Deployment**: Restart server → auto-migrate
- **Test**: Projects tab phải load được customers dropdown
- **Accessibility**: Tuỳ chọn, không blocking
