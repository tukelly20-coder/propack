-- Cách tạo phiên bản mới --
1. Tạo thư mục v{version} mới (ví dụ: v1.0.2)
2. Copy các file sau vào thư mục đó:

   - Mở mã liệu 打开链接VP.py

3. Cập nhật version.json trong thư mục đó
4. Cập nhật update_info.json trong thư mục gốc:
   - Sửa version thành "1.0.2"
   - Sửa version_folder thành "v1.0.2"
